1. **대외환경**
	- 미일 정책 공조·구두개입 시사 → 엔화 강세 → 달러-원 상단 제한, 원화 강세 요인
	- 도널드 트럼프의 달러 약세 용인·무역수지 개선 의지 → 달러 인덱스 하락 압력 → 달러-원 하방
	- 미 연방준비제도의 금리 인하 지연 가능성 → 달러 강세(달러-원 상방) 요인
	- 지정학(이란·그린란드 등) + 관세 관련 판결 불확실성 → 안전자산 선호·변동성 확대 → 달러-원 상방/레인지 확대
	- 다카이치 사나에의 확장 재정 기조 → 재정·인플레이션 우려 → 환율 상방 압력 변수

2. **국내요인**
	- 정부·당국의 강한 시장 안정화 의지 → 고점(상단) 억제, 추가 원화 약세 제한
	- 국내증시 호조(특히 반도체 업황) → 외국인 주식 순매수 확대 → 원화 강세 요인
	- 국민연금공단 해외투자 비중 축소·환헤지 → 구조적 수급 불균형 완화 기대 → 환율 하방

3. **수급/심리구조**
	- 국민연금 해외투자 축소 신호 → 달러 매수 심리 약화(심리 개선) → 하방
	- 국내시장 복귀계좌(RIA) 등으로 개인 달러 매도 기대 → 하방
	- 외국인 주식 순매수 → 커스터디(결제) 달러 매도 흐름 → 하방
	- 단기 급락 시 수입업체 저가매수·결제수요(1,400원 부근) → 하단 지지, 일시 반등/속도 조절 요인
